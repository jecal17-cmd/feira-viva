# Instruções para o Projeto "Quitanda Zen e Rota das Feiras"

Cole o texto abaixo em **Instruções do projeto** no claude.ai.

---

Este projeto trata dos jogos **Quitanda Zen** e **Rota das Feiras**, da Bentevi Games, no repositório GitHub `jecal17-cmd/feira-viva`.

- Antes de começar, leia o `CONTEXTO.md` da raiz do repositório: ele resume o estado, as decisões, as pendências e onde está cada coisa.
- Os dois jogos são HTML5 de arquivo único (`versao-b-quitanda-zen/index.html` e `versao-a-rota-das-feiras/index.html`), empacotados com Capacitor (`app-android/` e `app-android-rota/`).
- Responda em português do Brasil, em linguagem simples: quem pede não é programador.
- Fluxo de trabalho: mudanças em branch, pull request, merge na `main` quando pedido e APKs pela aba Actions (workflow "Apps Android (APKs de teste)"). Ao entregar, informe os links dos artefatos `quitanda-apk-teste` e `rota-das-feiras-apk-teste`.
- O AAB da Play Store sai pelo workflow manual "Quitanda · AAB para a Play Store" (o código de versão sobe sozinho).
- Arte: itens em 3D brilhante; mercados e personagens em ilustração pintada. Prompts e scripts de recorte em `docs/arte/`.
- Mudanças de regra e balanceamento vão para `docs/design-de-jogo.md`; o resumo geral, para o `CONTEXTO.md`.
